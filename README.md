# Uv Bichig (F.ITM202 Бие даалт)
Монгол бичиг суралцах хүсэлтэй хүн бүхэнд зориулсан.
## Ажиллуулах
Локал сервер хэрэгтэй (fetch + crypto): VS Code Live Server эсвэл `python -m http.server 8000`.
## Хуудас
index, login (бүртгэл+нэвтрэх), exerxise (сурсан зүйлээ шалгах, өөрийгөө сорих), people (найз), profile.
## Хэрэгжсэн / хэрэгжээгүй
- Хэрэгжсэн: бүртгэл (нууц үг SHA-256 хэшлэгдсэн), профайл, 5 төрлийн нийтлэл, таг, хайлт, like, сэтгэгдэл/хариулт, найз, нийгэмлэг.
- Хэрэгжээгүй: сервер/өгөгдлийн сан. Бүх өгөгдөл localStorage-д хадгалагдах тул өөр хөтөч, компьютерийн оюутнууд бие биеэ харахгүй. Файл хуваалцах, найзын хүсэлт зөвшөөрөх, мэдэгдэл, жинхэнэ аюулгүй байдал байхгүй.
- Үүнийг жинхэнэ платформ болгоход backend (жишээ нь Node.js + PostgreSQL эсвэл Firebase/Supabase) шаардлагатай.
- Туслах хэрэгсэл: Claude ашиглаж эхний хувилбарыг бэлдсэн.
